# 研究与应用概览

[中文](overview.md) · [English](overview.en.md) · [项目首页](../../README.md) · [结果与局限](results.md)

Endlexx 是项目主入口和本机 Agent 工作台；[Endless-XXX](https://github.com/ZerothXX/Endless-XXX) 是独立的角色视觉迁移研究仓库。这里集中呈现研究背景、方法、已接入的能力与版本边界，不复制维护另一套训练核心。

## 研究问题与方法

目标是将角色的发色、服装、配色和标志配饰迁移到不同主体，同时保留输入主体的类别、可见区域和构图。人物可以替换角色外观；动物和物品更适合通过配色、纹样与配饰表达角色关联，不能把所有输入都变成人。

1. 参考图和逐图标注提供角色监督。SDXL 底模、VAE 和文本编码器冻结，UNet LoRA 学习角色视觉特征。
2. 人工校对的角色卡优先描述身份；VLM 分析输入主体、可见区域和材质，降低识别错误污染角色身份的风险。
3. img2img 锚定输入，ControlNet-Canny 提供结构条件，SAM2 在启用时辅助掩码；不同主体使用不同生成强度和提示约束。
4. 保存结果、提示词、主体/规划/生成记录；通过固定输入、种子和权重进行人工比较。训练诊断 loss 不等于生成质量。

研究源码、模型布局、标准训练和 24GB 配置入口以 [研究仓库文档](https://github.com/ZerothXX/Endless-XXX#readme) 为准。应用的检索、修复和上下文工程见 [Endlexx 首页](../../README.md)。

## 两个仓库如何协作

| 内容 | 维护位置 | 应用中的关系 |
|---|---|---|
| 训练循环、数据预处理、研究推理策略 | Endless-XXX | 后续经明确版本评估再更新快照 |
| Agent、角色 RAG、多对话、上下文与资产 | Endlexx | 可独立运行；图像执行另需模型 |
| 推理适配、GPU 调度、任务日志 | Endlexx | 调用已安装的研究入口或随包快照 |
| 历史研究展示 | 原图在 Endless-XXX；精选副本在本仓库 | 有来源、提交号及哈希，不当作应用验收 |
| LoRA、角色包与第三方模型 | 单独准备/发布 | 不随源码包分发 |

## 后续接入的验收条件

- 更新快照时记录来源提交或本地源码哈希，保留上游单一训练实现。
- 明确角色包 schema、权重选择、触发词和底模依赖；不能只复制一个文件就宣称兼容。
- 先在隔离环境验证安装与回退，再覆盖人物、动物、物品、不同可见区域及失败恢复。
- 图像结果需保留种子、实际参数、模型/权重哈希及输入来源，并人工检查结构、身份、配饰和背景。
- 只有训练任务、状态、取消、输出和失败恢复全部接入并测试后，才将“应用内训练”标为已实现。

这些是后续工作标准，尚未交付的能力没有因首页改版而自动实现。当前运行与画质限制见 [发布验收](../RELEASE.md) 和 [结果页](results.md)。
