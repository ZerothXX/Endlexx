## 已知失败与验收边界

| 来源 | 已知问题 | 如何理解 |
|---|---|---|
| 历史研究说明 | 动物和物品仍需改进，人物相对较好 | 定性观察，不是统一基准或成功率 |
| Endlexx 真实迁移验收 | 明显色带和边缘伪影，单样例约 13 分钟 | 工具链执行成功，画质未达标；不同于本页历史图片 |
| Endlexx 一致性判断 | 缺失眼镜仍可能得到 unknown | 不可用作自动最终质量裁决 |
| LoRA 训练诊断 | 固定参考仍来自训练数据 | loss 下降或 best 选择不证明泛化、配饰还原或生成质量 |

应用验收证据与模型规划评测见 [质量报告](../Agent质量与改进验收.md)、[发布验收](../RELEASE.md)。本次文档改版没有重新执行大模型训练、推理或新增质量分数。

## 复现信息与缺口

[素材清单](../media/research/manifest.json) 给出每个本地文件、上游路径、固定提交 URL、Git blob SHA1、SHA256 和字节数。Git blob 标识与 GitHub 目录记录核对，打包再校验 SHA256。

历史图片的**实际种子、完整生效配置及所用 checkpoint 哈希未知**，在清单中以 `null` 保留。不能将当前默认参数或公开 LoRA 当作其准确生成记录。图片来源可追溯不等于实验已可精确复现。

后续实验至少记录：输入/参考来源与使用权限、角色卡和触发词、源码提交、完整生效配置、各模型和 LoRA 哈希、种子、分辨率、采样器、步数、强度、硬件、耗时、失败样本和人工评分规则。相同输入和固定种子比较 best/final 与不同策略；保留失败结果，避免只展示最好的一张。
