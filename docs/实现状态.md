# 实现与验收记录

日期：2026-10-24。首版为单人、本机工作空间，不宣称多租户生产系统。

本文保留首版历史计数。2026-10-25 模型与功能结果见 [Agent 质量报告](Agent质量与改进验收.md)，2026-10-26 源码发布及当前测试结果见 [发布验收](RELEASE.md)。

## 已实现

- React / TypeScript 工作台：角色、多个会话、资料与设定版本、图片上传、任务进度、取消/重试、图片对比与下载。
- FastAPI + SQLAlchemy；PostgreSQL / pgvector 主路径，SQLite 独立开发与测试路径。
- LangGraph 规划、工具执行与回答，SQLite 持久检查点；SQL 幂等键、执行结果回执和显式任务状态。
- 本地模型按实际输入 Token 校验上下文，优先移除最旧历史轮次，保留系统规则与当前请求；仍超出预算时返回可理解的澄清状态。
- 本地 4bit Qwen3-VL 控制器、Ollama 托管视觉模型、兼容 Chat Completions 的多 API 连接；密钥单独本机保存并按版本引用，不进入任务快照。
- BGE-M3 向量、中文 BM25、RRF、BGE Reranker；角色/资料版本过滤、原文引用、删除与重新索引。
- 自动修复：像素候选区域 → VLM 判别 → 连通区域内部蒙版 → LaMa → 原图保护区检查；不要求用户制作蒙版。
- Endless 正式迁移入口的进程适配、共享 GPU 锁、独立日志、任务超时与进程树取消。
- 按已确认档案和参考图生成一致性报告，分开记录承载部位可见性与特征对比，再计算状态；待定项最多复核一次，保留初始观察，复核异常不丢弃有效报告。
- 只读知识 MCP、Alembic 初始迁移、Compose 基础服务、CI 与验收脚本。
- Worker 进程锁、重启重新入队和已有工具回执恢复；输入档案/角色包清单与运行策略快照。
- 侧栏模型管理弹窗：API 添加/编辑/删除、本地模型选择与自动部署、固定多模型清单依次下载、真实字节进度、取消/重试和后台继续。角色输入框下方选择具体模型，主页功能卡只展示，所有新任务限定角色会话。
- 部署任务独立持久化；官方 Ollama ZIP 哈希校验、HF revision/断点身份校验、ZIP 路径保护，隔离运行时和已有权重复用。详细流程与边界见 [模型管理](模型管理.md)。
- Windows x64 首次启动自动检查/准备专用 Python、应用锁定依赖、Node/npm 与页面构建；默认 SQLite 和本地队列，不要求预装开发环境或 WSL。设置中提供环境诊断及本地/组合环境自动配置，部署前检查硬件，保留配置与失败原因。详见 [环境自动配置](环境自动配置.md)。

## 明确边界

- 自动定位当前是保守的浅色/深色局部色块缺损基线，尚不能保证划痕、复杂破损、透明遮挡等均可定位。失败时说明或自然语言澄清，不要求涂抹。
- LaMa 负责缺损补全；超分、去模糊、任意语义重绘尚未接入。PPO 旧检查点缺少原始 StateEncoder，未作为可复现模型启用。
- API 方案的图像执行仍使用本地工具，明确标注为「API 主控 + 本地工具」；没有外部密钥时不能实测第三方服务。
- 模型未训练角色说话方式；角色组织设定和创作资产，助手不进行人格扮演。
- 一致性检查属于实验功能。实际四项验收中，本地 4B 模型能区分已见服装/发色与画外鞋子，但对缺失眼镜返回 unknown，质量断言尚未通过；保留失败记录，不把“报告已生成”视为效果达标。
- 迁移真实接入已完成，但当前角色包样例存在明显伪影和外观迁移不足，视觉质量未通过验收。8GB 本机优化后单样例仍需约 13 分钟，需在 Endless 侧继续改进效果。
- 当前 checkpoint 存储为本地 SQLite，适合单台机器。分布式多副本交付前需改 PostgreSQL checkpointer，并补充租户身份、配额、存储授权与运维验证。
- Docker Compose 当前负责数据库和队列，API / Worker / 模型运行于原生环境。并未声称已完成全栈 GPU 容器化。
- 结构化 Trace 已持久化至本地。托管 Langfuse 尚未配置，默认不外发本地方案的内容。
- 恢复保证覆盖已经持久化回执的工具。外部工具完成与回执落库之间仍存在崩溃窗口，不宣称第三方计费请求具有绝对 exactly-once 保证。

## 本次已完成的验收

- 原有 18 项及本轮 11 项测试合计 29 项通过，新增连接隔离、密钥版本与任务快照、角色会话边界、真实字节续传、多文件进度汇总、Windows 原子写重试、哈希失败不发布、部署取消、ZIP 与不完整权重检查，以及规划格式校验和有界重试。
- 环境自动配置另有 11 项回归，覆盖依赖平台条件、配置保留、前端目录/产物、硬件阻塞、环境任务持久化/取消、响应脱敏、外部服务不被替换和 Windows 启动参数元数据；共 40 项后端测试。
- TypeScript 编译和 Vite 构建通过；6 项浏览器测试覆盖桌面、手机、角色范围、API 增删改/持久化、固定组合清单、重开弹窗后的下载进度，以及环境诊断/硬件阻塞和配置进度。进度渲染用受控响应验证，真实下载另外实测，二者不混为一项。
- 本机 Qwen3-VL-4B NF4 真实推理、BGE-M3 CPU 编码、BGE Reranker CPU 重排、PostgreSQL 向量距离查询已通过实测。
- 本轮已从官方来源下载、校验并启动托管 Ollama，完成 Qwen3-VL 2B Instruct 自动下载、真实文字和图片输入验证；固定组合复用已有环境/权重并自动补齐 SDXL 配置。两种连接在同一角色会话中切换并完成真实任务，记录见 `data/verification/model-switch.json`。默认使用显式 Instruct 标签，避免 Thinking 版本耗尽短规划预算。
