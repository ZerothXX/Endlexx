# Changelog

## 0.1.0 — 2026-10-26 (research preview)

- Character-scoped conversations, independent histories, deletion protection and cleanup.
- LangGraph planning, conditional tools, durable receipts, cancellation and retry.
- Extractive context compression with original-message retention and validation.
- Local/API controller profiles; text-controller and visual-model routing.
- Character RAG with BM25, BGE embeddings, RRF, reranking, citations and fallback.
- LaMa repair, Endless transfer adapter, experimental visual consistency reports.
- Windows setup, model management, environment diagnostics and read-only MCP.
- Chinese/English README, CI, release archive validation and reproducible source packaging.

Known quality failures remain: transfer artifacts and uncertain missing-accessory judgments.
This is a single-user local research preview, not a production or multi-tenant release.
No model weights, private data, or project-wide software license are bundled.
